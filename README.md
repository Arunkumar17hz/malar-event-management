## 🚀 Updating the site

1. Open the repo on GitHub → **Add file → Upload files**
2. Drag the changed files in (same names = they get replaced) → **Commit changes**
3. GitHub Pages rebuilds automatically in ~1 minute

## 🌐 Add your own domain (later)

1. Buy a domain (e.g. `malarevents.in`).
2. Search-replace `arunkumar17hz.github.io/malar-event-management` with your real domain in: `index.html`, `ta/index.html`, `sitemap.xml`, `robots.txt` (remove the `/malar-events` path part too).
3. In repo **Settings → Pages → Custom domain**, enter your domain, and set DNS at your registrar (CNAME → `arunkumar17hz.github.io`).
